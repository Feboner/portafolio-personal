# Portafolio Personal - Desarrollo Fullstack II (DSY1104)

Portafolio personal desarrollado como evaluación práctica en React, integrando componentes de Bootstrap, consumo de datos desde un archivo JSON, y pruebas unitarias.

## 🚀 Tecnologías utilizadas
* **React** (Framework frontend)
* **Bootstrap 5** (Estilos y diseño responsivo)
* **JavaScript (ES6+)**
* **Jasmine & Karma** (Pruebas unitarias)
